# 博士研讨会2026/10/29

静态手机阅读网站，发布目标为 GitHub Pages。

## 文件

- `index.html`：网站正文与全部样式、交互。
- `.nojekyll`：要求 GitHub Pages 直接提供静态文件，不运行 Jekyll。

## 后续更新

1. 将更新后的课堂记录 HTML 复制为 `index.html`。
2. 保留 `<head>` 中的标题、description、viewport、Open Graph 和 theme-color 元数据。
3. 在本地检查页面后提交并推送到仓库的发布分支。
4. 等待 GitHub Pages 完成部署，再访问公开网址确认不是 404 或登录页面。

本项目不需要构建工具或第三方依赖。
